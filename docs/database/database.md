## 🗂️ Tables

### `Tasks` Table

| Column | PostgreSQL Type | Nullable | Constraint |
|--------|----------------|----------|------------|
| `Id` | `integer` (IDENTITY) | NOT NULL | PRIMARY KEY |
| `Title` | `character varying(200)` | NOT NULL | Required |
| `Description` | `character varying(1000)` | NOT NULL | — |
| `Status` | `text` | NOT NULL | Stored as string |
| `Priority` | `text` | NOT NULL | Stored as string |
| `DueDate` | `timestamp with time zone` | NULL | Optional |
| `CreatedAt` | `timestamp with time zone` | NOT NULL | Auto UTC |
| `UpdatedAt` | `timestamp with time zone` | NULL | Auto UTC on update |

> **Note:** `Status` and `Priority` are stored as text (`"Pending"`, `"High"`) not integers. This is configured via `HasConversion<string>()` in `AppDbContext`.

## 🔗 Connection String

Defined in `TaskManager.API/appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=TaskManagerDb;Username=postgres;Password=YOUR_PASSWORD"
  }
}
```

Registered in `Program.cs`:

```csharp
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseNpgsql(builder.Configuration.GetConnectionString("DefaultConnection")));
```

## 🏗️ AppDbContext

```csharp
public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }

    public DbSet<TaskItem> Tasks => Set<TaskItem>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<TaskItem>(e =>
        {
            e.HasKey(t => t.Id);
            e.Property(t => t.Title).IsRequired().HasMaxLength(200);
            e.Property(t => t.Description).HasMaxLength(1000);
            e.Property(t => t.Status).HasConversion<string>();
            e.Property(t => t.Priority).HasConversion<string>();
        });
    }
}
```

**`OnModelCreating` Configuration:**

| Config | Effect |
|--------|--------|
| `HasKey(t => t.Id)` | Sets `Id` as Primary Key |
| `IsRequired()` | Column is NOT NULL |
| `HasMaxLength(200)` | VARCHAR(200) in DB |
| `HasConversion<string>()` | Enum stored as text |

## 🔄 EF Core Migrations

### What is a Migration?
A migration is an auto-generated C# file that contains SQL commands to create/modify the database schema.

### Commands Used

**Step 1 — Create Migration:**
```bash
cd TaskManager.API
dotnet ef migrations add InitialCreate
```
This generated: `Migrations/20260512080824_InitialCreate.cs`

**Step 2 — Apply Migration (Create DB + Tables):**
```bash
dotnet ef database update
```

This executed the following SQL in PostgreSQL:
```sql
CREATE DATABASE "TaskManagerDb";

CREATE TABLE "Tasks" (
    "Id"          integer GENERATED BY DEFAULT AS IDENTITY,
    "Title"       character varying(200) NOT NULL,
    "Description" character varying(1000) NOT NULL,
    "Status"      text NOT NULL,
    "Priority"    text NOT NULL,
    "DueDate"     timestamp with time zone NULL,
    "CreatedAt"   timestamp with time zone NOT NULL,
    "UpdatedAt"   timestamp with time zone NULL,
    CONSTRAINT "PK_Tasks" PRIMARY KEY ("Id")
);
```

## ⚠️ UTC DateTime — Important Fix

**Problem:**
PostgreSQL `timestamp with time zone` requires `DateTimeKind.Utc`.
Using `DateTime.Now` (Kind=Local or Unspecified) throws:

```
InvalidCastException: Cannot write DateTime with Kind=Unspecified
to PostgreSQL type 'timestamp with time zone', only UTC is supported.
```

**Solution applied in code:**

```csharp
// In TaskItem.cs — default value
public DateTime CreatedAt { get; set; } = DateTime.UtcNow;

// In TaskRepository.cs — on update
existing.UpdatedAt = DateTime.SpecifyKind(DateTime.UtcNow, DateTimeKind.Utc);

// In TasksController.cs — for DueDate from frontend
DueDate = dto.DueDate.HasValue
    ? DateTime.SpecifyKind(dto.DueDate.Value, DateTimeKind.Utc)
    : null
```
